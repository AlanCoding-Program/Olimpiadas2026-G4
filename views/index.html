¿Cómo puedo comprar un paquete o servicio turístico?

Para realizar una compra, primero debes registrarte o iniciar sesión. Luego puedes consultar las opciones disponibles, seleccionar la que desees y agregarla al carrito de compras

¿Cómo puedo realizar el pago de mi compra?

Una vez que hayas revisado los servicios seleccionados en el carrito, podrás continuar con el proceso de pago a través de la página.

¿Dónde puedo consultar mis pedidos?

Luego de iniciar sesión, podrás acceder a la sección correspondiente a tus pedidos y consultar aquellos que se encuentren pendientes.

¿Puedo modificar o eliminar un pedido?

No. Mientras el pedido se encuentre pendiente, podrás acceder a las opciones disponibles para modificarlo o eliminarlo.

¿Recibiré una confirmación después de realizar una compra?

Sí. Una vez realizada la operación, el sistema enviará un correo electrónico con la información correspondiente a la compra.
